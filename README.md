# Stock Dividend System

Hackathon project: On-chain stock dividend distribution using CashScript smart contracts on Bitcoin Cash (chipnet).

## Quick Start

### 1. Install dependencies

```bash
npm install
cd frontend && npm install
cd ../server && npm install
cd ..
```

### 2. Build frontend

```bash
npm run frontend:build
```

### 3. Start server (demo mode)

```bash
npm run server
```

### 4. Open the app

Open `http://localhost:3000` in a browser.

## Multi-laptop demo

One machine runs the server. Other laptops on the same network open the server's IP:

```bash
# On the server machine
npm run frontend:build
npm run server

# Find the server IP (one of these)
# Windows: ipconfig
# Mac/Linux: ifconfig | grep inet
```

Then from any browser on the same network: `http://<SERVER_IP>:3000`

All laptops see the same real-time state via WebSocket. Each picks a role (Company or Shareholder) on the login page.

## Architecture

```
Browser ─► http://server:3000 ─► Express + WebSocket
                                   ├─ demo mode: in-memory mock data
                                   └─ chipnet mode: ElectrumNetworkProvider (real BCH testnet)
                                                     │
                                                     └─ StockDividendVault.cash (CashScript smart contract)
                                                        ├─ Minting NFT vault
                                                        ├─ distribute(pk, sig, holder1, amt1, holder2, amt2)
                                                        └─ 2 holders per transaction (batchable)
```

## Chipnet mode

Requires `frontend/src/deployment.chipnet.json` (generated by genesis).

### Genesis (one-time token creation)

```bash
# Fund the deployer address with chipnet BCH first:
# https://chipnet.imaginary.cash/faucet

npm run genesis
```

This creates:
- Token IDs for each company
- CashScript vault contracts on chipnet
- Initial share distributions to holders
- Saves `deployment.chipnet.json`

### Run server in chipnet mode

```bash
cd server && SEED_PHRASE="your seed" npx tsx src/index.ts
```

The server loads live token balances from the blockchain.

## How it works

1. **Genesis**: Deployer creates token category + minting NFT vault per company
2. **Dividend**: Company declares a rate (e.g., 5%) via the web UI
3. **Smart contract**: `distribute()` verifies owner signature, mints new tokens, pushes to shareholders
4. **Real-time**: WebSocket broadcasts state changes to all connected clients
5. **Blockchain**: In chipnet mode, each dividend creates a real on-chain transaction

## Known limitations

- Contract distributes to 2 holders per transaction (batchable in production)
- `broadcastDividend` requires funded deployer UTXO for BCH fees
- Supply query in live mode takes ~15s (Electrum latency)
- Demos use the 12-word BIP39 seed `abandon...about` (test only)
